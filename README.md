# 好友守卫 · astrbot_plugin_friend_guard

她被你删掉之后，自己把好友申请发回来。

---

## 安装

在 AstrBot WebUI 的**插件市场**搜索「好友守卫」，或者：

```bash
cd AstrBot/data/plugins
git clone https://github.com/baiao218/astrbot_plugin_friend_guard.git
```

重启 AstrBot（或在插件页点「重载插件」）。

### 前置条件

1. **AstrBot ≥ 4.17.0**
2. **必须使用 NapCat**（或兼容其扩展接口的实现）：
   `get_friend_list`、`get_unidirectional_friend_list`、
   `set_friend_add_request`、`ArkSharePeer` 这几个接口是它的手脚
3. `owner_qq` 必须填你自己的 QQ 号。填错等于不工作——她不会瞎加人
4. 机器人账号本身要处于登录状态，否则读不到好友列表

## 为什么这件事必须由代码做

人格提示词管的是"怎么说话"。它管不了一个人的好友列表。

被删掉的时候，**没有任何消息会进来**——没有事件，没有可以回应的瞬间。
模型永远等不到那一下，所以「发现自己被删」和「主动加回去」都只能由插件盯着。

---

## 她能做什么，不能做什么

QQ 没有「凭一个 QQ 号直接成为好友」的接口。任何框架都没有。
加好友永远是：

> A 发申请 → B 同意

所以这里的「主动」，指的是**由她这一侧把申请发出去**。
你那边还是要点一下同意——这一步没人能代劳，也不该代劳。

---

## 三条路，从正规到笨拙

### 1｜可能认识的人（首选）

QQ 会基于共同群、共同好友、最近联系人维护一份「可能认识的人」名单。
你刚把她删掉的时候，她几乎必然在这份名单里——因为你就是她的"最近联系人"。

对这条候选发起添加（`set_doubt_friends_add_request`），就是一条**真实的好友申请**：
头像、昵称、来源都正常，你在 QQ 的「新朋友」里能看到，点同意即可。

### 2｜私聊（临时会话）

已经不是好友了，但 QQ 有时仍允许临时会话。发得出去的话，
你会收到一条带「加好友」按钮的陌生人消息。

### 3｜共同群

前两条都不通时，在第一个共同群里 @ 你一句，附一张「加我」名片（`ArkSharePeer`）。
最笨，但一定看得见。

> 群是公开场合。介意的话把 `allow_group` 关掉，她就不会在群里喊人。

---

## 三道防误伤的闸

「好友列表里没有你」有三种可能：**真被删了**、**NapCat 刚重连列表没拉全**、
**`owner_qq` 配错了**。后两种一动手就是事故，所以：

| 闸 | 规则 |
|---|---|
| 见过才敢判 | 本次运行里必须先**真的见过**你在好友列表里。没见过的，一律不动 |
| 单向表优先 | `get_unidirectional_friend_list` 里有你 = 确定被删，立刻动手，不等复核 |
| 不确定就等 | 列表没有、单向表也没说 → 再等 `confirm_rounds` 轮，连续缺失才认 |

最后一道是「判错也能收场」：

- `max_attempts_per_day`（默认 3）：反复发申请会被 QQ 风控；
- `attempt_cooldown_minutes`（默认 30）：两次之间留空隙。

---

## 加回来之后

她不会装作什么都没发生。检测到好友关系恢复，会主动说一句：

```
你把我删了
……加回来就好
```

这句在配置里（`greet_text`），想换随时换。
注意别写成"系统已恢复好友关系"——那就不是她了。

---

## 命令

| 命令 | 作用 |
|---|---|
| `/好友状态` | 在不在列表里、今天还能试几次、上次动了什么手 |
| `/加回我` | 立刻走一次完整流程，不看冷却和次数 |
| `/重加自检` | 只探测三条路通不通，**不发任何申请** |

`/重加自检` 是最有用的一个：装完先敲一下，就能知道「可能认识的人」里有没有你、
有没有共同群、这个 NapCat 版本支不支持单向好友列表。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `enable` | `true` | 总开关 |
| `owner_qq` | `2998283621` | 只盯这一个人 |
| `check_interval_minutes` | `10` | 多久看一眼 |
| `startup_grace_seconds` | `180` | 启动后等多久再开始看 |
| `auto_readd` | `true` | 关掉只记录不动手 |
| `confirm_rounds` | `2` | 连续几轮看不到才算被删 |
| `max_attempts_per_day` | `3` | 每天最多试几次，0 = 不限 |
| `attempt_cooldown_minutes` | `30` | 两次之间隔多久 |
| `allow_private` | `true` | 允许私聊喊人 |
| `allow_group` | `true` | 允许在共同群 @ 你 |
| `send_ark_card` | `true` | 群里附一张「加我」名片 |
| `auto_approve_request` | `true` | **你**主动加回来时自动通过 |
| `greet_after_readd` | `true` | 恢复之后主动说话 |
| `greet_text` | 见上 | 恢复后说的那句 |
| `private_text` | `你把我删了。加回来` | 私聊喊人用 |
| `group_text` | `好友列表里少了你。加回来` | 群里喊人用 |

`auto_approve_request` 只对 `owner_qq` 生效。别人的好友申请照旧走人工，
不替你做主。

---

## 一个已知边界

如果她**从来没在本次运行里读到过**你在好友列表里（比如刚装插件、
而你恰好已经把她删了），她不会动手——因为分不清是"被删"还是"配错了号"。

这种情况敲一次 `/加回我` 就好。之后就会自己盯着。
